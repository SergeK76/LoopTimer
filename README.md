# LoopTimer

Минималистичный циклический интервальный таймер для Android (Kotlin + Jetpack Compose) с мгновенным перезапуском кругов, зацикленным оповещением до нажатия **«ОК / Мьют»** и автоматической сборкой APK в GitHub Actions.

## Возможности

* **Циклическая работа без пауз:** по достижении `00:00:00` включается оповещение, а отсчёт нового круга стартует сразу без задержки.
* **Кнопка «ОК / Мьют»:** выбранный сигнал (системный звук, мелодия будильника или аудиофайл с устройства), вибрация и вспышка повторяются до нажатия **«ОК / Мьют»** (на главном экране или в уведомлении в шторке) либо **«Стоп»**.
* **Выбор интервала крутилками:** барабаны часов (`00–23`), минут (`00–59`) и секунд (`00–59`).
* **Статистика в реальном времени:** счётчик текущего круга и общее затраченное время.
* **Гибкие оповещения и экран:** выбор любого сигнала через системный диалог Android, включение/выключение вибрации, моргания вспышкой камеры и режима «Не выключать экран».
* **Светлая и тёмная темы:** переключение с сохранением настроек.
* **Фоновый сервис:** `Foreground Service` с `WakeLock` и уведомлением в шторке для стабильного отсчёта при заблокированном экране.

## Как скачать и установить APK

1. Открой вкладку **Actions** в этом репозитории и выбери последний успешный запуск **Build Android APK**.
2. Пролистай вниз до раздела **Artifacts** и скачай архив **LoopTimer-APK**.
3. Распакуй архив на устройстве Android и установи `app-debug.apk` (разрешив установку из выбранного источника, если система запросит).
4. После установки открой *Настройки → Приложения → LoopTimer → Батарея* и выбери **«Без ограничений»**, а также разреши уведомления и доступ к камере (если планируешь использовать вспышку).
